BorrowBox – Backend

BorrowBox is a campus-based item-sharing platform that allows students to lend and borrow items such as textbooks, calculators, chargers, and project materials.

Tech Stack

Node.js and Express.js

TypeScript

JWT Authentication

bcrypt for password hashing

Features

User authentication and authorization

Item listing and management

Borrowing requests and tracking

Notifications and wishlists

Reviews and user reputation

Admin dashboard and report management
